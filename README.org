#+TITLE: cava_plus_plus
#+AUTHOR: shyweeds

基于 Rust 的类 cava 终端音频频谱可视化程序。

* 依赖
- Rust（nightly / edition 2024）
- 系统库：=pkgconf=、=pipewire=、=alsa-lib=、=clang=
- 音频输入：PipeWire 的 =default_sink= 监听源

安装系统依赖（Arch Linux）：

#+begin_src sh
./install_deps.sh
#+end_src

* 构建与运行
#+begin_src sh
cargo run
#+end_src

按 =q= 退出。

* 实现
- =cpal= 采集音频 → =ringbuf= 环形缓冲 → =rustfft= FFT
- =crossterm= 在 alternate screen 中按帧绘制频谱条
- 输出使用绝对光标定位逐行绘制，不依赖换行符，避免 raw 模式下
  =OPOST= 关闭导致的画面横向错位
- 每根 bar 占 3 列、bar 之间空 1 列
- 惰性渲染：只重绘与上一帧不同的单元格
