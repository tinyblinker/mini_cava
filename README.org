#+TITLE: cava_plus_plus
#+AUTHOR: shyweeds

A terminal audio spectrum visualizer in Rust, similar to cava.

* Dependencies
- Rust (nightly / edition 2024)
- System libraries: =pkgconf=, =pipewire=, =alsa-lib=, =clang=
- Audio input: the =default_sink= monitor source of PipeWire

Install system dependencies (Arch Linux):

#+begin_src sh
./install_deps.sh
#+end_src

* Build and Run
#+begin_src sh
cargo run
#+end_src

Press =q= to quit.

* Implementation
- =cpal= captures audio -> =ringbuf= ring buffer -> =rustfft= FFT
- =crossterm= draws spectrum bars frame by frame in the alternate screen
- Output uses absolute cursor positioning, so it does not rely on newlines
  and avoids horizontal misalignment caused by =OPOST= being off in raw mode
- Each bar is 3 columns wide, with 1 empty column between bars
- Lazy rendering: only cells that differ from the previous frame are redrawn
- Attack/decay smoothing: bars rise fast and fall slowly instead of jumping
- Logarithmic frequency mapping: low frequencies get more bars
